# 내 체형은 무슨 유형? (bodytype-test)

가슴·허리·엉덩이 치수로 체형 유형을 알려 주는 1분 테스트 페이지. MBTI·심리테스트처럼 유형명을 재미있게 붙였다.
정적 HTML 하나(`site/index.html`), 서버·데이터베이스·추적 없음. **입력값은 브라우저 안에서만 계산되고 저장·전송되지 않는다.** 공유 링크에는 유형 이름만 담긴다.

- 공개 주소: https://minjoung1105-spec.github.io/bodytype-test/ (main 머지 시 GitHub Pages 로 자동 배포)
- 왜 만들었나(2026-10-12): "신체치수 → 체형 → 원하는 핏의 옷 추천" 앱의 첫 조각. 옷 치수 데이터는 크롤링 없이 얻기 어려워 앱은 보류하고, 체형 유형 테스트부터 웹으로 먼저 낸다.

## 분류 근거
- 여성 9유형: **FFIT**(Female Figure Identification Technique for Apparel; Simmons·Istook·Devarajan 2004, 수식 Lee·Istook·Nam·Park 2007). 인치 차이 규칙(가슴·엉덩이 차 3.6in, 가슴–허리 9in, 엉덩이–허리 10in, 윗엉덩이/허리 1.193)을 cm 입력에서 변환해 쓴다. 타원·다이아몬드는 "허리가 가슴·엉덩이보다 큰 경우" 로 묶었다(플러스사이즈 수정 연구 방식).
- 남성 5유형: 학계 표준이 없어 업계 분류(역삼각·사다리꼴·직선·삼각·타원)를 같은 차이 규칙으로 나눈다. 페이지에 그렇게 적혀 있다.
- 허리/엉덩이 비율: WHO 2008 (여 0.85 · 남 0.90). 건강 메모일 뿐 진단이 아니라고 페이지에 적혀 있다.
- "재미로 보는 특징"(성격·식습관)은 **과학적 근거가 없다** 고 페이지에 명시한다. 체형→성격 연결은 심리학에서 폐기된 가설이다.

## 바꾸는 법
`site/index.html` 의 `TYPES` 가 유형 카드(이름·설명·재미·핏), `classifyF`/`classifyM` 이 규칙이다. 규칙을 바꾸면 README 의 근거 절도 같이 고친다.
